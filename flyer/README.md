# ハロウィン コスプレ フライヤー

## イベント情報

- **イベント**: コスプレ
- **文言**: 仮装で盛り上がる特別な2日間
- **日程**: 10/30（金）・10/31（土）
- **OPEN**: 20:00

## ファイル

| ファイル | 用途 |
|---|---|
| `samples/halloween-sample-01.jpg`〜`20.jpg` | デザイン違いサンプル 20点 |
| `gallery.html` | サンプル一覧ビュー |
| `index.html` | Web / 印刷用 HTML フライヤー |
| `halloween-flyer.jpg` | 代表画像（sample-01） |

## 使い方

1. `gallery.html` をブラウザで開き、気に入った番号を選ぶ
2. 対応する `samples/halloween-sample-XX.jpg` を配布・印刷
3. 文言・OPEN時間の微調整は `index.html` を編集

「ガールズバー」表記は入れていません。
