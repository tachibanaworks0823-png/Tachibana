# ハロウィン ガールズバー フライヤー

## ファイル

| ファイル | 用途 |
|---|---|
| `halloween-girlsbar-flyer.jpg` | 画像版フライヤー（SNS・印刷向け） |
| `index.html` | Web / 印刷用 HTML フライヤー |

## イベント情報

- **日程**: 10/30（金）・10/31（土）
- **OPEN**: 20:00
- **Dress code**: costume welcome

## 使い方

- 画像: `halloween-girlsbar-flyer.jpg` をそのまま配布・印刷
- HTML: ブラウザで `index.html` を開き、印刷（A4縦）またはスクショ

店名・住所・電話を差し替える場合は `index.html` の文言を編集してください。
