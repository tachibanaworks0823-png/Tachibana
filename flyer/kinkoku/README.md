# 謹告フライヤー（風俗向け）A4

風俗店舗向けの公式「謹告」告知フライヤーです。偽サイト・偽求人への注意喚起を内容としています。

## 完成ファイル

| ファイル | 用途 | サイズ |
|---|---|---|
| `kinkoku-fuzoku-a4.png` | A4印刷・配布用 | **2480 × 3508**（210×297mm / 300dpi） |
| `index.html` | デザイン原版 | A4 |

## 内容（風俗定型）

- 偽サイト・偽求人・類似名称の無断使用への警告
- 公式以外のスカウト／LINE勧誘への注意
- 登録料・保証金・前払い金を要求する悪質業者への注意
- 店名を騙った無許可営業・斡旋への注意
- 損害責任の否認と法的措置の告知

## 印刷

- **用紙**: A4
- **形式**: PNG
- **推奨**: フチなし印刷、または余白最小
- 店名・日付はフッター「当　店」「令和　　年　　月　　日」を差し替えて使用

## 再書き出し

```bash
python3 flyer/kinkoku/render_a4.py
```
