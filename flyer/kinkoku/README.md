# 謹告フライヤー（風俗向け）A4

風俗店舗向けの公式「謹告」告知フライヤーです。偽サイト・偽求人への注意喚起を内容としています。

## 完成ファイル

| ファイル | 用途 | サイズ |
|---|---|---|
| `kinkoku-fuzoku-a4.png` | A4印刷・配布用 | **2480 × 3508**（210×297mm / 300dpi） |
| `index.html` | デザイン原版 | A4 |

## 内容（入店お断り・謹告）

- 18歳未満の入店お断り
- 暴力団関係者・反社会的勢力の入店お断り
- 泥酔・迷惑行為・危険物所持等の入店お断り
- 該当時の入店拒否・退店要請および法的措置の告知

## 印刷

- **用紙**: A4
- **形式**: PNG
- **推奨**: フチなし印刷、または余白最小
