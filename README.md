# Tachibana — モニター用スライドショー

店舗モニター向けの全画面スライドショーです。シャンパン・システム・ドリンク・ご案内を自動で切り替えます。

## 使い方

1. `index.html` をブラウザで開く（ローカルサーバー不要）
2. `F` キーで全画面表示（キオスク／モニター向け）
3. 約9秒ごとに自動で次のスライドへ

### 操作

| キー | 動作 |
|------|------|
| `→` / `←` | 次／前のスライド |
| `Space` | 一時停止／再開 |
| `F` | 全画面切替 |

## 料金・文言の変更

`index.html` 内の各スライド文言・金額を直接編集してください。

- スライド1: ブランド（Tachibana）
- スライド2: シャンパンメニュー
- スライド3: システム料金
- スライド4: ドリンク
- スライド5: 営業案内

表示時間は `app.js` 先頭の `SLIDE_DURATION_MS`（初期値 `9000`）で変更できます。

## デザイン

深夜のラウンジを意識したダークトーン＋ゴールドのトーン。モニター常時表示を想定し、操作UIはアイドル時に非表示になります。
