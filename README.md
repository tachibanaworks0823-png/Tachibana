# Tachibana — モエシリーズ デザイン案

店舗モニター向けスライドのデザイン検討用です。

## 確認方法

1. `index.html` を開く（ギャラリー）
2. 各カードからデザイン案を全画面表示
3. デザイン内で `←` `→` で前後移動、`Esc` / `G` でギャラリーへ
