# Tachibana — モニター用スライドショー

店舗モニター向けの全画面スライドショーです。スライドは順次追加していきます。

## 現在のスライド

1. **モエシリーズ** — モエシロ / ロゼ / 黒 / アイス / ピカ

## 使い方

1. `index.html` をブラウザで開く（ローカルサーバー不要）
2. `F` キーで全画面表示（キオスク／モニター向け）

### 操作

| キー | 動作 |
|------|------|
| `→` / `←` | 次／前のスライド（複数枚ある場合） |
| `Space` | 一時停止／再開 |
| `F` | 全画面切替 |

料金・文言は `index.html` を直接編集してください。
